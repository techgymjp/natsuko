# 司令塔 — 判断力を鍛える歴史シミュレーション

歴史上の危機で司令塔の椅子に座り、不完全な情報と制限時間の中で決断を下すブラウザゲーム。

## 収録作戦(各5局面)
| 作戦 | あなたの立場 | 1判断の持ち時間 |
|---|---|---|
| キューバ危機 (1962) | 米国大統領 | 90秒 |
| アポロ13号 (1970) | フライト・ディレクター | 75秒 |
| ミッドウェー海戦 (1942) | 第一航空艦隊司令長官 | 60秒 |
| エンデュアランス号 (1915) | 探検隊長 | 90秒 |
| チリ鉱山落盤事故 (2010) | 救出作戦の責任者 | 90秒 |
| ハドソン川の奇跡 (2009) | 機長 | 30秒 |

## 仕組み
- 入電に誤報が混じる。「裏を取る」で真偽を確かめられるが時間を使う
- AI参謀3人(慎重派・攻撃派・データ至上)のうち誰かが、もっともらしく間違える
- 決裁ごとに確信度と理由を入力。結果には運の要素がある
- 振り返り: 判断と結果のマトリクス、5つの軸のレーダー、判断の癖、局面ごとの誤報とAIの穴、もしも年表
- 今日の1判断(日替わり10問・連続記録)、判断プロフィール、対戦コードで友人と比較
- BGMと効果音はすべて Web Audio API でその場で合成(音声ファイルなし)

## 遊び方
`index.html` をブラウザで開くだけ。ビルド不要。記録はブラウザの localStorage に保存される。

## 構成
- `index.html` — 画面とスタイル
- `js/scenarios.js` — 6作戦のデータ
- `js/daily.js` — 今日の1判断のデータ
- `js/audio.js` — BGM・効果音の合成エンジン
- `js/game.js` — ゲーム進行と画面
