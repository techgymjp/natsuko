# Google Play ストア掲載情報(下書き)

Play Console の「ストアの掲載情報」に貼り付けて使います。既定の言語を日本語にし、「翻訳を管理」から英語(en-US)を追加してください。英語の文面は `listing-en.txt` にもあります。

## 画像(このフォルダ)

| 用途 | ファイル | サイズ |
| --- | --- | --- |
| アプリのアイコン | `icon-512.png` | 512 × 512 |
| フィーチャー グラフィック(日本語) | `feature-graphic.png` | 1024 × 500 |
| フィーチャー グラフィック(英語) | `feature-graphic-en.png` | 1024 × 500 |
| スマートフォンのスクリーンショット(日本語) | `ja-1-title.png` 〜 `ja-8-daily.png` | 1080 × 1920 |
| スマートフォンのスクリーンショット(英語) | `en-1-title.png` 〜 `en-8-daily.png` | 1080 × 1920 |

スクリーンショットの並び(おすすめの順)

1. `1-title` タイトル画面
2. `2-reports` 入電。誤報に「要注意」の判が押される
3. `3-advisors` 3人のAI参謀の進言
4. `4-verdict` 決裁の結果
5. `5-review` 判断と結果のマトリクス
6. `7-timeline` もしも年表(史実と違う道を選ぶと世界線が分かれる)
7. `6-missions` 作戦の一覧
8. `8-daily` 今日の1判断

## 日本語

**アプリ名**(30 文字以内)

```
司令塔：歴史の危機で鍛える判断力
```

**簡単な説明**(80 文字以内)

```
キューバ危機、アポロ13号、ハドソン川。歴史の危機で指揮を執り、限られた時間と不完全な情報で決断する
```

**詳しい説明**

```
歴史に残る危機の中心で、決めるのはあなたです。

核戦争まで13日のホワイトハウス。酸素が漏れ続けるアポロ13号の管制室。両エンジンを失った旅客機の操縦席。
情報は不完全で、時間はなく、頼りのAI参謀は時々もっともらしく間違えます。
限られた時間の中で、何を信じ、何を選ぶか。判断力を筋トレのように鍛える歴史シミュレーションです。

■ 20の作戦
・キューバ危機、アポロ13号、ミッドウェー海戦、桶狭間の戦い、黒船来航、江戸城無血開城、南極探検、チリ鉱山落盤事故、ハドソン川の奇跡など
・易しい作戦から順に挑み、1つを終えると次の作戦の鍵が開く
・各作戦は5つの局面。1つの判断に制限時間があり、時間切れは「決められなかった」という決断になる

■ 判断を鍛える仕組み
・入電には誤報が混じる。「裏を取る」と真偽が分かるが、持ち時間を使う
・慎重派・攻撃派・データ至上の3人のAI参謀が進言する。誰かがもっともらしい理屈で間違えることがある
・決裁のたびに確信度を入れる。自信過剰か、控えめすぎかが見えてくる
・結果には運の要素がある。筋の良い判断が不運で失敗することも、悪い判断が運よく成功することもある

■ 作戦の後の振り返り
・結末と、史実で実際にどう判断されたかが明かされる
・「判断の質」と「結果」を分けて評価するマトリクス
・判断の質、決断速度、情報の見極め、AI参謀の見極め、確信度の精度の5つの軸
・局面ごとの誤報の正体と、AI参謀の推論の穴
・史実と違う道を選んだときの「もしも年表」
・史実の判断が最善だったとは限らない。その理由も解説

■ 毎日続けられる
・今日の1判断:日替わりで1問、3分で終わる歴史のジレンマ(30問)。連続日数を記録
・判断プロフィール:すべての作戦から、あなたの判断の癖を描く
・友人と比べる:対戦コードを送り合い、同じ局面での判断を並べて比べる

■ その他
・作戦ごとに音楽と効果音が変わる(モールス信号、宇宙船の交信音、氷の割れる音など)
・日本語・英語対応
・遊ぶのに登録は不要。記録は端末の中だけに保存
・史実の記述は広く知られた資料に基づいていますが、ゲームとして状況を単純化しています

あなたの判断は、歴史を変えられるか。
```

## Play Console「アプリのコンテンツ」の回答の目安

- **プライバシー ポリシー**: https://techgym.jp/privacy-policy/
- **広告**: 「はい、広告を含みます」
- **アプリのアクセス権**: 「制限なし(ログイン不要)」
- **広告 ID**: 「使用する」(目的は「広告またはマーケティング」と「アナリティクス」)
- **ターゲット ユーザー**: 13 歳以上(13 歳未満を含めると広告に制限がかかる)
- **データ セーフティ**: アプリ自体は個人情報を集めない(記録は端末内だけ)。Google AdMob が「デバイスまたはその他の ID(広告 ID)」と「アプリの操作(広告の表示・クリック)」を広告とアナリティクスの目的で収集・共有する。通信は暗号化されている。※ AdMob の公式ガイドに従って最終確認すること
- **コンテンツのレーティング**: ゲーム。戦争・事故・災害を扱うが、文章での描写のみで、流血や残酷な画像はない。実在の出来事での死者に触れる(敬意を持った事実の記述)。ギャンブル、性的表現、薬物の使用を促す表現はない
- **ニュース アプリ / 健康 / 金融など**: いずれも該当しない
